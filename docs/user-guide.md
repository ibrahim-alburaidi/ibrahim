# دليل الاستخدام

## المسار الأول: مراجعة الملف دون تشغيل

افتح [README](../README.md)، ثم [السيناريو](../examples/scenario.md)، ثم [ملف التسليم](../outputs/handover.md). اضغط على أي معرف مصدر لمعرفة النص الأصلي. راجع الأسئلة المفتوحة وخطة المتابعة. تصفح المحاور السبعة بالترتيب لفهم المنهجية والأمثلة.

## المسار الثاني: تجربة نصية مع الذكاء الاصطناعي

1. اختر أداة محادثة متاحة لك؛ لا يتطلب المشروع مزودًا بعينه.
2. انسخ الأمر P01 من [المكتبة](../01-prompt-engineering/prompt-library.md).
3. أرفق نص [raw-input.md](../examples/raw-input.md) كاملًا، مع المعرفات. لا تستخدم بيانات عمل حساسة في التدريب.
4. اطلب كشف التعارضات والفجوات باستخدام P02 وP03 مع المدخلات نفسها.
5. احتفظ بالناتج الأول كما ظهر، وطبّق P06 للمراجعة. راجع بنفسك؛ رأي النموذج الثاني ليس إثباتًا مستقلًا.
6. قارن 8 مهام رئيسية بالمرجع. إذا فُصلت بيانات نور كمهمة مستقلة في الناتج، راجع نطاق العد قبل حساب الدقة؛ لا تعد اختلاف التجميع وحده اختلاقًا.
7. جهز رسالة وخطة باستخدام P04 وP05، ثم سجّل مراجعتك الفعلية.
8. لا تستخدم P07 للادعاء بإنجاز المهام دون سجل متابعة جديد.

احفظ التجربة محليًا في `local-results/` المستثنى من Git: مدخل، أمر، مخرج خام، مخرج مصحح، وسجل قياس. هذا توجيه للتجارب القادمة؛ لم ننشئ تشغيلًا فعليًا نيابة عنك.

## ما يجب أن يظهر في نتيجة جيدة

T04 يعرض الموعدين دون حسم؛ T06 يبقى غير مفعّل؛ T02 لا يتحول إلى فاتورة مصروفة؛ T07 مفتوح مجددًا؛ T05 مرتبط ببيانات نور. مسؤولية سارة مؤكدة للعرض والمخزون، ولا تعمم على باقي المهام.

## تغيير السيناريو

أضف مصادر مرقمة جديدة وحدّث الأوامر والمخرجات؛ احتفظ بالمصادر القديمة. في سيناريو آخر عدّل أيضًا شروط الفحص الخاصة بالعينة الحالية؛ السكربت ليس مدققًا عامًا لكل أنواع ملفات التسليم. راجع [التوثيق الفني](technical-documentation.md).

## مشاكل شائعة

| المشكلة | المعالجة |
|---|---|
| لا يوجد Python | يمكن قراءة المشروع وتجربة الأوامر دون تشغيل فحص Python |
| الأمر python غير معروف | جرّب python3 أو py على Windows إن كان Python مثبتًا |
| النموذج اختلق مسؤولًا | قارن المصدر، صحح إلى غير محدد، وسجل الخطأ |
| ظهر تاريخ واحد للطلب | أعد المراجعة باستخدام M06 وM07 وN01؛ لا تقبل الحسم بلا دليل |
| اختلاف الناتج عن المثال | راجع المعنى والمصادر؛ تطابق الألفاظ ليس معيار النجاح |
| فشل الفحص بعد تعديل المدخل | اقرأ رسالة الخطأ وحدث المخرجات/المرجع باتساق؛ لا تتجاوز الفشل دون فحص |
