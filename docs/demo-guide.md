2. **المدخلات — 45 ثانية:** اعرض M06 وM07 وM10 لبيان اختلاف الموعد والصلاحية المعلقة.
3. **آلية العمل — 60 ثانية:** اعرض أمر P01 وقاعدتي عدم اختلاق التفاصيل وإرفاق المصدر.
4. **النتيجة — 60 ثانية:** افتح ملف التسليم، ثم انتقل من T04 إلى مصدريه، ومن T06 إلى السؤال المفتوح.

6. **التوثيق والإصدارات — 30 ثانية:** اعرض README والمحاور وGit log ونتيجة الفحص إن شغّلته.
7. **التطوير — 30 ثانية:** اشرح خطة قياس الزمن والدقة، وأن الأثر لم يُقَس بعد.
