# المراجع وأصالة المحتوى

استُلهم تنظيم المحاور السبعة ومنهجية العرض من المستودعين اللذين حددهما المستخدم:

1. [محللة الحلول الرقمية](https://github.com/Hajer207/ai-workplace-productivity-digital-solutions).
2. [مساعد البحث الأكاديمي](https://github.com/mohamedguesmi1992-gif/ai-workplace-productivity-portfolio).
3. [حساب أكاديمية سدايا](https://github.com/SDAIAAcademy).

سيناريو «بديل» ومدخلاته وأمثلة مخرجاته وتوثيقه أُنشئت لهذا المشروع بمساعدة الذكاء الاصطناعي. لا تُنسب أسماء أصحاب الأمثلة أو مراجعاتهم البشرية إلى المتدرب الحالي. لم تُنسخ بياناتهم الشخصية أو نصوص أمثلتهم إلى المشروع.

توسعات الأطر كما وردت في الأمثلة: C.A.R.E. = Context, Action, Rules, Expected Output؛ وR.C.T.O. = Role, Context, Task, Output. يستخدم المشروع هذه التعريفات باتساق.
