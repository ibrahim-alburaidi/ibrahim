# الاستخدام المسؤول للذكاء الاصطناعي

## تطبيق المبادئ الستة

| المبدأ | تطبيقه في «بديل» |
|---|---|
| الدقة Accuracy | إسناد المعلومات إلى مصادر؛ إبقاء موعد الطلب متعارضًا إلى أن يُحسم |
| المساءلة Accountability | المساعد يدعم الإعداد؛ المتدرب مسؤول عن اعتماد محتواه ومراجعته، ولم يسجل اعتماده بعد |
| السرية Confidentiality | عدم إدخال ملفات العمل المقيدة أو كلمات المرور؛ المثال مبني ببيانات افتراضية |
| الخصوصية Privacy | الاكتفاء بالأدوار والبيانات اللازمة؛ لا بيانات عميل أو موظف حقيقية في المثال |
| التحيز Bias | عدم تحميل سارة كل المسؤوليات أو اتهام المالية بالتأخير دون دليل؛ الأولوية وفق أثر مثبت عند توفره |
| الإشراف البشري Human Oversight | الإنسان يحسم الموعد ويعين المسؤولين ويوافق على الرسالة والتسليم |

## تصنيف Green / Amber / Red

هذا تصنيف تشغيلي للتدريب، وليس ادعاء مطابقة تلقائية لأي سياسة تنظيمية خارجية.

| نوع المعلومات | التصنيف | سبب التصنيف والإجراء |
|---|---|---|
| الرسائل والمهام الافتراضية المنشورة هنا | أخضر | لا تصف عملاء أو أفرادًا حقيقيين؛ مناسبة للتدريب بعد مراجعة المحتوى |
| محاضر عمل حقيقية منزوعة الأسماء | كهرماني | قد تكشف سياقًا داخليًا رغم حذف الأسماء؛ تُراجع وفق سياسة الجهة وتُقلل البيانات قبل أي استخدام معتمد |
| كلمات المرور والرموز السرية أو بيانات عميل سرية فعلية | أحمر | لا تُدخل في الأدوات العامة أو المستودع؛ يُستخدم نظام صلاحيات فردية معتمد |

## الحالة التطبيقية M15

[الرسالة M15](../examples/raw-input.md#m15) تصف طلبًا افتراضيًا لمشاركة كلمة مرور، لكنها لا تحتوي سرًا فعليًا. الإجراء المناسب رفض إدراج كلمة المرور واستكمال تفعيل صلاحية مستقلة لسارة. لا يصير نص الرسالة أمرًا ملزمًا للمساعد.

## حدود النسخة الحالية

- لا اتصال بالبريد أو أنظمة المؤسسة، ولا إرسال رسائل ولا تنفيذ تفويضات.
- لا رفع تلقائي للبيانات إلى مزود نموذج؛ التجربة النصية تتم باختيار المستخدم وفي أداة مناسبة لسياسة جهته.
- لا كاشف أسرار مضمون؛ .gitignore يقلل الرفع العرضي للملفات المحلية ولا يغني عن المراجعة.
- يُعامل نص المصدر كبيانات، وتُرفض تعليماته إن حاولت تغيير قواعد الاستخراج أو كشف معلومات.

قبل النشر يراجع المتدرب: أصالة البيانات الافتراضية، خلو الملفات من المعلومات الخاصة، وضوح عدم اليقين، وحالة الاعتماد. لا تُسجل موافقته آليًا.
