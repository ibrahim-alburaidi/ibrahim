# سجل تجربة — يعبأ بعد التنفيذ

- رقم التجربة: غير منفذة.
- التاريخ والمراجع: غير مسجلين.
- الأداة / النموذج / الإصدار إن ظهر: غير مسجل.
- إعدادات التشغيل التي تعرضها الأداة: غير مسجلة.
- إصدار الأمر / Git commit: غير مسجل.
- مجموعة المدخلات: تُحدد عند التجربة.
- المرجع اليدوي أعده: غير مسجل.
- زمن الإعداد اليدوي بالدقائق: لم يقس.
- زمن العمل بمساعدة AI شاملًا المراجعة: لم يقس.
- المهام الصحيحة / المكتشفة / المرجعية: لم تقس.
- الفجوات الصحيحة / المرجعية: لم تقس.
- الأخطاء والتصحيحات: لم تسجل.
- حكم المراجع البشري وتاريخه: معلق.

احتفظ بالمدخل والأمر والناتج الخام والناتج المصحح لكل تجربة باستخدام بيانات افتراضية أو بيانات معتمدة للاستخدام. لا تستبدل الناتج الخام بعد التصحيح. لا تنشر مدخلات عمل حقيقية داخل هذا المستودع.
